# Project Charter

## Product Name

AntiSlop

## Vision

Build a personal web app for daily coding practice with automatic judging and streak tracking, focused on learning DSA fundamentals from scratch.

## Product Principles

1. Learning-first over feature-heavy
2. Beginner-friendly problem progression
3. Fast feedback loop (run, fail, improve)
4. Consistency through daily streak
5. Clear documentation for long-term maintainability

## Non-Goals (for MVP)

- Public multi-user platform
- Social features (leaderboards, discussions)
- Multiple solve languages
- AI hints and tutoring
- Contest mode

## Locked Decisions

- Platform: Web app only
- Audience: Single user (owner only)
- Product language: English
- Solve language: Python 3.12 only
- Auth: Not required in MVP
- Hints: Not required in MVP

## Success Criteria (MVP)

- User can solve at least one problem end-to-end (write code, run, submit, get verdict)
- Daily challenge can be generated and tracked on a calendar
- Streak updates correctly after accepted submission
- At least 30 beginner problems available across core topics
